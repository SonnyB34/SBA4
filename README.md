# Task Managment App 

 A simple task manager built with HTML, CSS and JavaScript. Tasks are saved in the browser with localStorage, so they are still there after you refresh the page.

 ## How It Works

 1. Enter a task name, category and deadline, then choose a status.

 2. Click Add Task. The task appears in the Task list and is saved to localStorage.

 3. Click Delete on a task to remove it from the list and from localStorage.

 ## How to Run

 1. Clone the repository

 2. Open index.html in your browser.
